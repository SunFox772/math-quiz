# 随机数学口算题生成器

一个用 Python 写的命令行口算练习程序，随机生成加、减、乘、除四则运算题，支持输入校验和负数答案。

## 功能

- 随机生成指定数量的口算题
- 支持加、减、乘、除四种运算
- 除法题目保证整除，答案一定是整数
- 减法允许出现负数结果
- 输入非整数时自动提示并重新作答
- 题目数量必须为正整数，输错会重新询问

## 运行环境

- Python 3.6+
- 仅使用标准库 `random`，无需额外安装依赖

## 使用方法

1. 克隆仓库：

   ```bash
   git clone https://github.com/SunFox772/math_quiz.git
   ```

2. 进入项目目录：

   ```bash
   cd math_quiz
   ```

3. 运行程序：

   ```bash
   python src/main.py
   ```

4. 按提示输入题目数量，然后逐题作答。

## 示例

```
欢迎使用随机数学口算题生成器！
请输入题目数量: 3
题目 1: 45 + 78 = 123
回答正确！
题目 2: 30 - 67 = -37
回答正确！
题目 3: 12 * 8 = 96
回答正确！
```
